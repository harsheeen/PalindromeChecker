
## Use Case 2
**Application 1:** Logic to check whether the hardcoded string is a palindrome.

---

## Description
This program demonstrates a simple palindrome check using Java:

- Hardcode the input string  
- Use a `for` loop to check whether the input string is a palindrome  
- If yes → print **"Is it Palindrome – True!"**  
- If no → print **"Is it Palindrome – False!"**
